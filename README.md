# 软考高项学习助手 (Gaoxiang Study)

一个基于 OpenClaw 的 Agent Skill，帮助备考软考高项（信息系统项目管理师）。

## 📚 功能特性

### 1. 智能教材查询
- 完整加载 24 章软考高项教材
- 根据问题关键词自动定位章节
- 引用原文并给出总结答案

### 2. 真题练习系统 ⭐
- 收录 **333道** 近3年高项真题（选择题）
- 按24章分类，每章独立JSON文件
- 随机抽题、自动判分、详细解析
- 错题自动归档到个人错题本

### 3. 问题归档系统（错题本）
- 自动记录错题和疑难问题
- 追踪复习次数，识别薄弱环节
- 重复提问时提示历史答案

### 4. 每日定时复习
- 每天早上 **7:58:08**（错峰+吉利秒数）自动推送 3-5 个问题
- 8:08:08 重试任务兜底（整点8分8秒，发发发）
- 基于艾宾浩斯遗忘曲线安排复习
- 通过飞书/钉钉直接接收

## 🚀 安装方法

### 1. 克隆仓库

```bash
cd ~/.openclaw/workspace/skills
git clone https://github.com/luohaisi/gaoxiang-study-skill.git gaoxiang-study
cd gaoxiang-study
```

### 2. 配置定时任务（可选）

默认定时任务配置（已内置）：
- **主任务**：每天 **7:58:08** 推送（"我要发"，错峰吉利时间）
- **重试任务**：每天 **8:08:08** 推送（"发发发"，兜底保障）

```bash
# 查看定时任务
openclaw cron list

# 如需修改推送时间
openclaw cron update <jobId> --schedule "8 58 7 * * *"
```

**注意**：秒级 cron 格式为 `秒 分 时 日 月 周`，例如 `8 58 7 * * *` 表示每天 7:58:08

## 💬 使用方法

### 基本提问

直接问任何高项相关问题：

```
用户：什么是WBS？怎么分解？
AI：【第9章 项目范围管理】WBS是工作分解结构...
    分解步骤：1.识别可交付成果 2.确定结构...
    （已记录到问题档案）
```

### 真题练习

```
用户：给我出一道挣值分析的真题
AI：【第11章 项目成本管理 - 挣值分析真题】
    
    某项目BAC=560万元，AC=200万元，EV=160万元...
    
    A. 730  B. 630  C. 750  D. 650
    
用户：我猜是C
AI：✅ 答案正确！
    解析：CPI = EV/AC = 0.8，EAC = AC + (BAC-EV)/CPI = 700...
    （答对的题不加入错题本）
```

### 查看错题本

```
用户：我的错题本
AI：📋 你的错题本（共X道）
    
    1. 【第8章】变更请求类型辨析
       你的答案：C. 预防措施
       正确答案：A. 纠正措施
       错误原因：混淆"重新与计划一致"和"确保未来符合"
    
    2. ...
```

### 按章节刷题

```
用户：给我出几道第8章的真题
AI：【第8章 项目整合管理】
    
    第1题：项目章程可由发起人编制...
    ...
```

### 复习推送

每天早上 **7:58:08** 自动收到：

```
📚 高项复习提醒

早上好！今天来复习几个错题：

1. 【第8章】在监控项目工作过程中，当遇到变更请求时...
   你上次答错了，正确答案是 A. 纠正措施
   
2. 【第9章】WBS的100%原则是什么？
   💡 答案要点：下级之和=上级，不多不少刚刚好

回复题号查看详细解析，或告诉我你的答案来检验学习效果！
```

**推送时间说明**：
- 主推送：7:58:08（整点前，避开 8:00 高峰期拥堵）
- 重试兜底：8:08:08（万一主任务失败，10分钟后补发）

1. **定时任务测试**：安装后务必测试早上 **7:58:08** 推送是否正常
2. **复习计数**：每个问题默认复习3次后不再推送
3. **真题来源**：近3年（2023-2025）高项真题，持续更新
4. **教材版本**：基于最新版高项教材（24章完整版）
5. **推送时间**：已设置为 7:58:08 和 8:08:08（错峰+吉利秒数），避免整点高峰期任务拥堵

## 🔧 故障排查

### 定时任务不推送

检查 `scripts/daily_review.py` 中的配置：
- `USER_ID` 是否为你的飞书用户 ID
- `openclaw message send` 命令参数是否正确

### 错题本为空

需要先做题或手动添加问题，档案才有内容推送。
